블로그의 콘텐츠는 "글" 한 종류만 있는 게 아닙니다. 공들여 쓴 긴 글과 스치듯 떠오른 생각을 적어 둔 짧은 글이 같은 목록에 섞이면 서로 방해가 됩니다. astro-blog는 콘텐츠를 두 가지 형태로 나누고, 쌓여 가는 콘텐츠를 위해 아카이브와 필터를 마련해 사이트가 커져도 둘러보기 좋게 유지합니다.

## 두 가지 콘텐츠 형태

### 글: 완전한 형태의 글쓰기

글은 정식 장문 콘텐츠입니다. 제목, 부제, 커버, 카테고리, 태그, 다국어 버전까지 빠짐없습니다. 홈페이지 목록과 아카이브에 나타나며 사이트의 본체를 이룹니다.

### 노트: 날짜로 적는 짧은 콘텐츠

노트는 더 가벼운 존재입니다. 파일 이름이 날짜+제목이고 본문은 몇 문장이면 됩니다. 그날의 아이디어 하나, 링크 하나, 인용 하나를 기록하기에 알맞아 "글로 완성해야 한다"는 부담이 없습니다. 초안 스위치로 숨겨 두었다가 준비되면 공개할 수 있습니다.

## 아카이브: 오래된 콘텐츠를 다시 찾을 수 있게

### 시간순 아카이브 페이지

글이 많아지면 홈페이지 페이징만으로는 부족합니다. 아카이브 페이지는 모든 글을 시간순으로 나열하고, 제목과 설명 역시 다국어를 지원합니다. 다시 찾아온 독자가 옛 글을 찾는 가장 빠른 길입니다.

### 카테고리와 태그

모든 글에는 카테고리 하나와 태그 여러 개가 있습니다. 카테고리는 큰 방향을, 태그는 세밀한 주제를 담당하며, 둘 다 아카이브와 홈페이지 필터에서 쓰입니다.

## 홈페이지 필터: 직접 정한다

글 목록 위의 필터 바는 고정되어 있지 않습니다. 설정에서 할 수 있는 일:

- "이번 달 글"과 "인기 글" 두 가지 내장 필터의 켜기/끄기;
- 카테고리 필터와 태그 필터를 원하는 만큼 추가;
- 각 필터의 버튼 문구와 매칭 값을 다섯 언어로 모두 지정.

인기 글은 각 글 자신의 `popular` 표시로 결정됩니다. 조회 수 통계 같은 복잡한 장치는 없습니다——데이터베이스가 없는 정적 사이트에서는 이 단순함이 오히려 신뢰성입니다.

## 읽기 경험의 디테일

- 다크 모드는 시스템을 따르거나 직접 전환할 수 있고, 토글 버튼은 사이트의 ◐ 상징;
- 글 페이지는 다단계 제목, 표, 코드 강조, 이미지, 오디오·동영상 삽입을 지원하며 예시 글에 전체 데모가 있습니다;
- 모바일은 따로 다듬었습니다. 목록에서는 커버를 숨기고, 글 단독 화면에서는 둥근 모서리를 없애고 구분선으로 바꿔 작은 화면에서도 깔끔합니다.

콘텐츠 쪽 소개는 여기까지입니다. 다음 글에서는 무대 뒤로——이 파일들을 위해 만든 관리 화면, astro-blog-admin을 다룹니다.
